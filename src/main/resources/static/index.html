ICD-10 Lookup API

This service now runs as a backend-only ICD-10 lookup API for examination workflows. Use the endpoints below from your hospital backend or frontend integration layer.

Core Endpoints

  • GET /api/diagnosis/search?q=J18&limit=10 returns ranked ICD-10 suggestions.
  • GET /api/diagnosis/code/J18.9 resolves a canonical ICD-10 record by code.
  • GET /api/actuator/health/readiness reports readiness, DB state, and ICD dataset availability.
